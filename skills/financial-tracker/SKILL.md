# 💰 Financial Tracker Skill

**Description:** Track costs, ROI, and budget for autonomous operations.

## Metrics Tracked

### Cost Metrics
- Tokens per task
- Cost per task (€)
- Cost by model (kimi-k2.6, qwen3-coder, etc.)
- Daily/weekly/monthly totals
- Most expensive tasks

### Value Metrics
- Revenue generated (if trackable)
- Time saved vs manual work
- Error prevention value
- Opportunity cost captured

### Budget Management
- Monthly budget limit
- Alert at 50%, 75%, 90%
- Auto-optimize: Suggest cheaper models
- ROI per skill/feature
