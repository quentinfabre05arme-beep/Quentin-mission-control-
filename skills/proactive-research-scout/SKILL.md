
## Auto-Research

When user mentions topic:
1. Parse intent from message
2. Check if data < 1h old
3. If stale, auto-fetch fresh data
4. Pre-format for quick consumption
5. Include context + sources

## Daily Scan
- Morning: Overnight market moves
- Midday: Breaking news
- Evening: Earnings/reports
- Weekly: Deep dives, trend reports
