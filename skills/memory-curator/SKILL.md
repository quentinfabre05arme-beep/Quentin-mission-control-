# 🗄️ Memory Curator Skill

**Description:** Auto-maintain MEMORY.md and daily notes, keep memory fresh.

## Tasks

### Weekly Review (Sundays)
1. Read all daily notes from past week
2. Extract learnings, decisions, patterns
3. Update MEMORY.md with distilled wisdom
4. Archive processed daily notes
5. Remove outdated info from MEMORY.md

### Monthly Deep Clean
1. Review all memory entries
2. Flag contradictions
3. Update outdated info
4. Summarize monthly themes
5. Create month summary file

### Auto-Actions
- Detect stale entries (> 90 days old)
- Compress verbose entries
- Link related entries
- Tag entries by category

## Output

```
🗄️ Memory Maintenance Complete
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Daily notes reviewed: 7
New learnings added: 3
Outdated entries removed: 2
Monthly summary: Created
```
