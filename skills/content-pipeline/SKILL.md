# ✍️ Content Pipeline Skill

**Description:** Research → Draft → Review → Publish workflow.

## Workflow

### 1. Research Phase
- Gather data on topic
- Analyze trends
- Collect sources
- Identify angles

### 2. Draft Phase
- Create outline
- Write thread/post
- Add visuals/data
- Format for platform

### 3. Review Phase
- Fact-check claims
- Verify sources
- Check tone
- Preview output

### 4. Publish Phase
- Schedule optimal time
- Cross-post if relevant
- Track performance
- Engage with replies

## Auto-Actions
- Research → Auto-draft when data collected
- Suggest timing based on engagement history
- A/B test headlines (2 variants)
- Track: Views, likes, replies, click-through

## Platforms
- X/Twitter (primary)
- Telegram channel
- Newsletter (weekly digest)
