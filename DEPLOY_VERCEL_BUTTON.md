# 🚀 Deploy to Vercel

Click this button to deploy your dashboard:

[<img src="https://vercel.com/button" alt="Deploy with Vercel">](https://vercel.com/new/clone?repository-url=https://github.com/quentinfabre05arme-beep/mission-control-hub&root-directory=mission_control)

Or manually:
1. Go to https://vercel.com/new
2. Import GitHub repo
3. Select `mission-control-hub`
4. Set root directory: `mission_control`
5. Deploy!
