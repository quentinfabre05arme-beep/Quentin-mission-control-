FAQ

Do I need coding skills?

No. I handle installation, configuration and tuning. You only need to approve external actions like posting or spending.

Where does it run?

On your own Windows PC, a rented VPS, or a home server. You keep full control and data sovereignty.

What security measures are included?

Gateway bound to localhost, encrypted credential storage, least-privilege API tokens, sandbox mode, device audit, and a documented kill switch. I also scan installed skills for known issues.

Can I add more skills later?

Yes. The agent is designed to be extended. Future skills can be installed from ClawHub or built custom.

Is there a guarantee?

Yes — 30-day satisfaction guarantee on all setup packages. If the agent isn't delivering value, I'll fix it or refund.
